The strict integer parser accepts canonical ASCII decimal integers in the signed 64-bit range. It rejects plus signs, leading zeros, negative zero, whitespace, non-ASCII bytes and overflow. Rejections return zero and false.

Run `python3 test/integer/run.py` on Linux. Set `ODIN` or pass `--odin` if the compiler is installed elsewhere. The runner builds debug and optimized helpers and checks a deterministic corpus against an independent Python grammar and arbitrary-precision arithmetic oracle. It includes exhaustive one-byte and two-byte inputs, signed boundaries, digit mutations, random values and oversized slices. Each page-sized input is also placed against both inaccessible memory boundaries to detect out-of-slice reads. `--seed` changes the random corpus; `--output` saves the result and corpus hash.
